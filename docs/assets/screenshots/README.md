# Screenshots

Drop PNG (or JPG) screenshots into this folder using the filenames below, and they'll
automatically show up in the "Screenshots" section of the GitHub Pages site
(`docs/index.html`) — no other changes needed.

| Filename              | Where it's used            |
|------------------------|-----------------------------|
| `listing-search.png`   | Ride search / listings page |
| `my-bookings.png`      | "My Bookings" page          |
| `my-listings.png`      | "My Listings" page          |
| `my-passengers.png`    | "My Passengers" page        |

A 16:10 crop (e.g. 1600×1000) of the relevant page works best with the current layout.
If you want to swap the filenames or add more, edit the `.shot` blocks in
`docs/index.html` and point each one at your actual image (an `<img>` tag instead of
the current placeholder icon + text).
